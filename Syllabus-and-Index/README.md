**Savitribai Phule Pune University (SPPU)**  
**Faculty of Science and Technology**  
**Fourth Year Computer Engineering (2019 Course)**  
**Academic Year**: 2026–27  
**Course**: Laboratory Practice III (410246)  
**Teaching Scheme**: Practical: 4 Hours/Week  
**Examination Scheme**: Term Work: 50 Marks | Practical / Oral: 50 Marks  

---

## Course Objectives
1. To understand, analyze, and implement classical algorithm design strategies (Greedy, Dynamic Programming, Backtracking, Branch and Bound).
2. To apply modern Machine Learning models for classification, regression, clustering, and deep representation learning on real-world datasets.
3. To gain foundational and practical exposure to decentralized technologies, cryptocurrency transactions, Ethereum Virtual Machine (EVM), and Solidity smart contracts.

---

## Course Outcomes (COs)
- **CO1**: Formulate, analyze, and implement algorithmic solutions using appropriate paradigms and compute asymptotic time/space complexities.
- **CO2**: Design and deploy supervised and unsupervised machine learning pipelines including preprocessing, feature scaling, model training, and performance metrics evaluation.
- **CO3**: Develop, compile, test, and deploy secure distributed smart contracts on Ethereum using Remix IDE and MetaMask wallet.

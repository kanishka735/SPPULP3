# Practical 5: Survey Report on Blockchain Platforms & Applications

## Objective
Prepare a comprehensive survey and analytical report on Blockchain Technology, evaluating public vs. private distributed ledger platforms, consensus mechanisms, smart contract execution engines, enterprise use cases, scalability bottlenecks, and security trade-offs.

---

## Executive Summary
Blockchain is a decentralized, distributed, and immutable append-only ledger secured through cryptographic hashing and distributed consensus algorithms. Originally conceptualized for electronic peer-to-peer cash (Bitcoin), modern programmable blockchains (such as Ethereum, Hyperledger Fabric, and Solana) serve as universal settlement layers and decentralized computing environments.

---

## Comparative Analysis of Major Blockchain Frameworks

| Feature | Bitcoin | Ethereum | Hyperledger Fabric | Solana |
| :--- | :--- | :--- | :--- | :--- |
| **Type** | Public / Permissionless | Public / Permissionless | Enterprise / Permissioned | Public / High-Performance |
| **Consensus** | Proof-of-Work (PoW) | Proof-of-Stake (PoS) | Raft / PBFT | Proof-of-History + PoS |
| **Smart Contracts** | Script (Limited) | Solidity / Vyper (EVM) | Go / Java / Node.js (Chaincode) | Rust / C (BPF) |
| **Throughput (TPS)** | ~7 TPS | ~15–30 TPS (L1) | 3,000+ TPS | 2,000–50,000 TPS |
| **Finality Time** | ~60 minutes (6 blocks) | ~12–15 minutes | Immediate / Milliseconds | ~400 milliseconds |
| **Target Sector** | Digital Store of Value | DeFi, NFTs, dApps | Supply Chain, Banking, Gov | High-frequency trading, Web3 |

---

## Key Industry Use Cases
1. **Supply Chain Provenance**: End-to-end tracing of pharmaceutical products and organic agriculture, eliminating counterfeit goods.
2. **Decentralized Finance (DeFi)**: Trustless lending, automated market makers (AMMs), and collateralized debt without traditional banking intermediaries.
3. **Healthcare & Electronic Health Records (EHR)**: Patient-consented cryptographic data access across disparate hospital management networks.
4. **Digital Identity Management**: Self-sovereign identity (SSI) using zero-knowledge proofs (ZKPs).

---

## Challenges and Future Trends
- **Scalability**: Layer 2 rollups (Optimistic & ZK-Rollups), proto-danksharding (EIP-4844).
- **Interoperability**: Cross-chain messaging protocols (Chainlink CCIP, LayerZero).
- **Regulation & Compliance**: Anti-money laundering (AML), Travel Rule, and carbon emission footprint optimization.
